# 早見表(チートシート)

`README.md` と演習(Issue)に出てくるタグ・プロパティ・操作の一覧です。忘れたら、まずここを見てください。本文で概念から説明しているものは「詳しい説明」に章名を書いています。

> [!TIP]
> **HTMLのタグは100種類以上、CSSのプロパティは500種類以上あります。覚えようとしないでください。** 実務では必要になったときに調べます。大事なのは、下の「よく使うもの」が読めることと、開発者ツールで確かめられることです。

## HTMLの骨組み

| タグ | 意味 |
|---|---|
| `<html>` | ページ全体 |
| `<head>` | 画面に表示されない情報(タイトル、CSSの読み込みなど) |
| `<body>` | 画面に表示される中身すべて |
| `<link rel="stylesheet" href="...">` | CSSファイルを読み込む。`<head>` の中に書く |

## よく使うHTMLタグ

| タグ | 意味 | 詳しい説明 |
|---|---|---|
| `<h1>` 〜 `<h6>` | 見出し。数字が小さいほど大きい見出し | 本文「HTMLとCSSの役割分担」 |
| `<p>` | 段落 | 本文「HTMLとCSSの役割分担」 |
| `<a href="...">` | リンク | 本文「HTMLの部品」 |
| `<img src="..." alt="...">` | 画像。`alt` は画像が読めない人向けの説明文 | このチートシートのみ |
| `<ul>` / `<ol>` / `<li>` | 箇条書き(順序なし / 順序あり)と、その項目 | このチートシートのみ |
| `<div>` | 意味を持たない、ただの入れ物 | このチートシートのみ |
| `<span>` | 意味を持たない、文中の一部を囲む入れ物 | このチートシートのみ |
| `<header>` `<main>` `<footer>` `<section>` `<nav>` | `<div>` と同じ入れ物だが、**意味がついている** | このチートシートのみ |

**`<div>` と `<section>` はどちらも入れ物ですが、後者には「ここは1つのまとまりです」という意味があります。** 意味のあるタグを選ぶと、検索エンジンや読み上げソフトが構造を理解できます。

## よく使う属性

| 属性 | 意味 | 詳しい説明 |
|---|---|---|
| `class` | 名札。**同じ名前を何個つけてもよい。CSSはほぼこれで狙う** | 本文「HTMLの部品」 |
| `id` | 名札。**ページ内で1つだけ。強すぎるのでCSSでは避ける** | 本文「HTMLの部品」 |
| `href` | リンク先 | 本文「HTMLの部品」 |
| `src` | 読み込み元 | 本文「HTMLの部品」 |
| `style` | CSSを直接書く。**強すぎるので使わない** | 本文「なぜCSSが効かないのか」 |

## CSSのセレクタ

| 書き方 | 選ぶもの | 強さ | 詳しい説明 |
|---|---|---|---|
| `p` | すべての `<p>` | 弱 | 本文「CSSの当て方」 |
| `.notice` | `class="notice"` の要素 | 中 | 本文「CSSの当て方」 |
| `#page-title` | `id="page-title"` の要素 | 強 | 本文「CSSの当て方」 |
| `.card p` | `.card` の中にあるすべての `<p>` | — | 本文「CSSの当て方」 |
| `.card > p` | `.card` の**直接の子**である `<p>` だけ | — | このチートシートのみ |
| `a:hover` | マウスが乗っているときの `<a>` | — | このチートシートのみ |

**強さ(詳細度)の順**: `!important` > `style` 属性 > `#id` > `.class` > `タグ名`

## 大きさと余白

| プロパティ | やること | 詳しい説明 |
|---|---|---|
| `width` / `height` | 大きさ。**既定では content の大きさを指す** | 本文「ボックスモデル」 |
| `padding` | 枠の**内側**の余白 | 本文「ボックスモデル」 |
| `border` | 枠線。`1px solid #ccc` のように「太さ 種類 色」で書く | 本文「ボックスモデル」 |
| `margin` | 枠の**外側**の余白 | 本文「ボックスモデル」 |
| `box-sizing: border-box` | **`width` を「箱全体」の意味に変える。** 実務ではほぼ必ず入れる | 演習02 |

**書き方の省略形**

| 書き方 | 意味 |
|---|---|
| `padding: 10px` | 上下左右すべて 10px |
| `padding: 10px 20px` | 上下 10px、左右 20px |
| `padding: 10px 20px 30px 40px` | 上・右・下・左(時計回り) |
| `margin: 0 auto` | 上下 0、左右自動 = **中央寄せ**。実務の定番 |

## 文字と色

| プロパティ | やること |
|---|---|
| `color` | 文字色 |
| `background` | 背景色・背景画像 |
| `font-size` | 文字の大きさ |
| `font-weight: bold` | 太字 |
| `line-height` | 行の高さ。`1.7` のように倍率で書くと読みやすい |
| `text-align: center` | 文字の中央寄せ(**要素そのものは動きません**) |
| `text-decoration: none` | リンクの下線を消す |

**色の書き方**: `red` のような名前、`#1f6f66` のような16進数、`rgb(31, 111, 102)`。実務では16進数が多いです。

## 並べる(Flexbox)

| プロパティ | やること | 詳しい説明 |
|---|---|---|
| `display: flex` | 子要素を**横並び**にする。現代のレイアウトの主役 | 演習04 |
| `gap: 16px` | 並べた要素同士の隙間 | 演習04 |
| `justify-content: space-between` | 主軸(横)方向の並べ方。両端に寄せて間を空ける | 演習04 |
| `justify-content: center` | 主軸方向の中央に寄せる | 演習04 |
| `align-items: center` | 交差軸(縦)方向を中央に揃える | このチートシートのみ |
| `flex-wrap: wrap` | 入りきらないとき、**折り返す**(既定は折り返さない) | 演習04 |
| `flex-direction: column` | 並べる向きを縦に変える | 演習05 |
| `display: none` | **要素を消す**(場所も取らなくなる) | このチートシートのみ |

**迷ったら `display: flex` → `gap` → `justify-content` の順で足していきます。** これだけで大半のレイアウトが組めます。

## 画面幅で出し分ける(メディアクエリ)

```css
@media (max-width: 720px) {
  .container {
    width: 100%;
  }
}
```

| 書き方 | 意味 | 詳しい説明 |
|---|---|---|
| `@media (max-width: 720px) { ... }` | 画面幅が720px**以下**のときだけ適用 | 演習05 |
| `@media (min-width: 720px) { ... }` | 画面幅が720px**以上**のときだけ適用 | このチートシートのみ |

**確認は開発者ツールのデバイスモードで。** 推測せず、実際に幅を変えて見てください。

## フォーム

| タグ・属性 | やること | 詳しい説明 |
|---|---|---|
| `<form>` | 入力欄をまとめる入れ物 | 本文「フォーム」 |
| `<label for="id名">` | 入力欄の名札。**`for` と入力欄の `id` を一致させる** | 演習06 |
| `<input type="text">` | 1行のテキスト入力 | 本文「フォーム」 |
| `<input type="email">` | メールアドレス用 | 本文「フォーム」 |
| `<input type="checkbox">` | チェックボックス | 本文「フォーム」 |
| `<textarea>` | 複数行のテキスト入力 | 本文「フォーム」 |
| `<button type="submit">` | 送信ボタン。**`<div>` で代用しない** | 演習06 |
| `required` | 入力必須にする | このチートシートのみ |
| `placeholder="..."` | 未入力時に薄く表示される例文 | このチートシートのみ |
| `maxlength="200"` | 入力できる最大文字数 | このチートシートのみ |

> [!WARNING]
> **`for` の値と `id` の値が1文字でも違うと、ラベルは効きません。** エラーは出ないので、開発者ツールで見比べて確認するしかありません。

## この教材では扱わないが、この先すぐ使うもの

| 用語 | 意味 |
|---|---|
| レスポンシブ対応 | 画面幅に応じて見た目を変えること。`@media` というルールを使う |
| CSS設計(BEM など) | クラス名の付け方の流儀。人数が増えると、名前が衝突しないルールが要る |
| CSS-in-JS / Tailwind | CSSファイルを書かずにスタイルを当てる新しい方式。本編のReactで出てきます |
| アクセシビリティ | 目が見えない人・マウスが使えない人でも使えるようにすること。`alt` や意味のあるタグはこのため |
