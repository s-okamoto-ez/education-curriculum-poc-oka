# 早見表(チートシート)

`README.md` と演習(Issue)に出てくる構文・用語の一覧です。忘れたら、まずここを見てください。本文で概念から説明しているものは「詳しい説明」に章名を書いています。

> [!TIP]
> **構文を暗記する必要はありません。** 現場のエンジニアも毎回調べています。暗記すべきものがあるとすれば、それは「エラーメッセージの読み方」だけです。

## 実行する

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `node ファイル名.ts` | TypeScriptのファイルを実行する。**型はチェックされない** | 本文「演習を始める前に」 |
| `npm install` | そのフォルダに必要な道具を入れる。初回だけ | 演習02 |
| `npm run typecheck` | 型チェックだけを行う(実行はしない) | 演習02 |
| `console.log(値)` | 値を画面に出す。**デバッグの基本にして最強の道具** | 本文全体 |

> [!IMPORTANT]
> **`node` は型をチェックしません。型を消してから実行しています。** 型チェックは `npm run typecheck` を自分で走らせるか、エディタの赤い波線で見ます。

## 変数

| 書き方 | 意味 | 詳しい説明 |
|---|---|---|
| `const x = 1;` | 後から**入れ替えない**箱。**まずこちらを使う** | 本文「プログラムは上から順に動く」 |
| `let x = 1;` | 後から入れ替える箱 | 本文「プログラムは上から順に動く」 |
| `const x: number = 1;` | 型を明記して作る | 本文「型」 |

**`const` の注意点**: `const` が禁じているのは「**箱そのものの入れ替え**」だけです。中身が配列やオブジェクトの場合、**その中身は変えられます**(演習01のパート3)。

```typescript
const names = ["田中"];
names.push("佐藤");   // OK。中身を足しただけ
names = ["鈴木"];      // エラー。箱ごと入れ替えようとした
```

## 基本の型

| 型 | 入るもの | 例 |
|---|---|---|
| `number` | 数値(整数も小数も) | `1200`, `1.1`, `-3` |
| `string` | 文字列 | `"こんにちは"`, `'abc'` |
| `boolean` | 真偽 | `true`, `false` |
| `null` | 「値が無い」ことを明示したもの | `null` |
| `undefined` | 「まだ何も入っていない」状態 | `undefined` |
| `number[]` | 数値の配列 | `[1, 2, 3]` |
| `string[]` | 文字列の配列 | `["a", "b"]` |

**`null` と `undefined` の違い**: `null` は「無いと決めた」、`undefined` は「決めていない・見つからなかった」。存在しない配列の要素を読むと `undefined` が返ります(演習01のパート7)。

## オブジェクトと型の定義

```typescript
type User = {
  id: string;
  name: string;
  isPremium: boolean;
};

const tanaka: User = {
  id: "u1043",
  name: "田中",
  isPremium: true,
};

console.log(tanaka.name);   // 田中
```

| 書き方 | 意味 | 詳しい説明 |
|---|---|---|
| `type 名前 = { ... }` | 型に名前をつける | 演習02 |
| `オブジェクト.項目名` | 項目を読む | 演習02 |
| `項目名?: 型` | **省略してもよい**項目 | このチートシートのみ |

## 文字列の組み立て

| 書き方 | 例 | 結果 |
|---|---|---|
| バッククォート | `` `${name}さん` `` | `田中さん` |
| `+` でつなぐ | `"a" + "b"` | `"ab"` |

**バッククォート(` ` `)を使ってください。** `+` でつなぐと、数値と文字列が混ざったときに事故ります(演習01のパート4)。

## 計算

| 記号 | 意味 |
|---|---|
| `+` `-` `*` `/` | 足す・引く・掛ける・割る |
| `%` | 割った余り |
| `Math.round(x)` | 四捨五入 |
| `Math.floor(x)` | 切り捨て |

> [!WARNING]
> **`+` は、片方が文字列だと「連結」になります。** `1200 + "3"` は `1203` ではなく `"12003"` です。掛け算 `*` は数値に変換しようとするので `3600` になります。**この非対称さが、実務で本当に事故ります。**

## 比較

| 記号 | 意味 |
|---|---|
| `===` | **同じ**(型も値も) |
| `!==` | 違う |
| `>` `<` `>=` `<=` | 大小 |
| `&&` | かつ |
| `\|\|` | または |
| `!` | 否定 |

> [!IMPORTANT]
> **必ず `===` を使ってください。`==` は使いません。** `==` は型が違っても勝手に変換して比べるため、`0 == "0"` が `true` になります。原因追跡の邪魔にしかなりません。

## 条件分岐

```typescript
if (count > 10) {
  console.log("多い");
} else if (count > 0) {
  console.log("少ない");
} else {
  console.log("ゼロ");
}

// 短く書きたいとき(三項演算子)
const label = isPremium ? "プレミアム" : "無料";
```

**「偽」として扱われるもの**: `false` / `0` / `""`(空文字) / `null` / `undefined`。それ以外は全部「真」です。**`if (stock)` は `stock` が `0` のとき偽になります**(演習01のパート5)。数を判定したいときは `if (stock === 0)` のように明示してください。

## 繰り返し

```typescript
// 配列の中身を1つずつ(いちばんよく使う)
for (const name of names) {
  console.log(name);
}

// 回数を指定して
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

## 配列でよく使うもの

| 書き方 | やること |
|---|---|
| `arr.length` | 個数 |
| `arr[0]` | 最初の要素(**0から数える**) |
| `arr.push(x)` | 末尾に足す |
| `arr.map(f)` | 全部を変換して**新しい配列**を作る |
| `arr.filter(f)` | 条件に合うものだけの**新しい配列**を作る |
| `arr.find(f)` | 条件に合う**最初の1つ**。無ければ `undefined` |
| `arr.reduce((acc, x) => ..., 初期値)` | 全部を1つの値にまとめる(合計・件数など) | 
| `arr.join("\n")` | つないで1つの文字列にする |

**`find` が `undefined` を返しうることが、演習03の不具合の入口です。演習04で `filter` `map` `find` `reduce` を実装します。**

## 関数

```typescript
function withTax(price: number): number {
  return Math.round(price * 1.1);
}

// 短い書き方(アロー関数)。中身は同じ
const withTax2 = (price: number): number => Math.round(price * 1.1);
```

| 部分 | 呼び方 | 詳しい説明 |
|---|---|---|
| `price: number` | 引数(入口) | 本文「関数」 |
| `: number`(かっこの後) | 戻り値の型(出口) | 本文「関数」 |
| `return` | 値を返して、そこで関数を抜ける | 本文「関数」 |

## ファイルをまたぐ

```typescript
// 出す側
export function renderPost() { ... }

// 受け取る側
import { renderPost } from "./post.ts";
```

`./` は「同じフォルダ」です。**コマンドライン基礎でやった相対パスとまったく同じ考え方**です。

## 時間がかかる処理(async / await)

```typescript
async function loadTimeline(): Promise<void> {
  try {
    const posts = await fetchTimeline();
    console.log(posts.length, "件");
  } catch (error) {
    console.log("失敗:", (error as Error).message);
  }
}
```

| 書き方 | やること | 詳しい説明 |
|---|---|---|
| `async function` | 「この中に時間のかかる処理がある」という宣言 | 本文「時間がかかる処理」 |
| `await 式` | その式(Promise)の結果が返るまで待つ | 本文「時間がかかる処理」 |
| `try { ... } catch (e) { ... }` | 失敗を受け止める。**書き忘れるとプログラムが落ちる** | 演習05 |
| `(e as Error).message` | 受け止めたエラーから、メッセージ文字列を取り出す | 演習05 |

> [!WARNING]
> **`await` に来た瞬間、プログラムはそこを保留にして、外の同期処理を先に進めます。** `async` 関数の外にある `console.log` のほうが、中身より先に実行されることがあります。詳しくは演習05。

## DOM操作(画面を動かす)

| 書き方 | やること | 詳しい説明 |
|---|---|---|
| `document.querySelector(".count")` | CSSのセレクタで要素を1つ探す | 本文「画面を動かす」 |
| `document.querySelectorAll(".card")` | 当てはまる要素を全部探す | このチートシートのみ |
| `el.textContent = "3件"` | 中の文字を書き換える | 本文「画面を動かす」 |
| `el.addEventListener("click", f)` | クリックされたときの処理を登録する | このチートシートのみ |

**セレクタの書き方は HTML/CSS基礎で学んだものと同じ**です。`.クラス名`、`#id名`。

## エラーの読み方(最重要)

| 出てくるもの | 意味 |
|---|---|
| `TypeError` | 値の種類が想定と違う。**`undefined` の中身を読もうとした**が最頻出 |
| `ReferenceError` | その名前の変数が存在しない。**打ち間違いを疑う** |
| `SyntaxError` | 書き方が壊れている。**かっこの閉じ忘れを疑う** |
| `at 関数名 (ファイル:行:桁)` | スタックトレース。**一番上が落ちた場所** |
| `node_modules/...` の行 | 他人のコード。**まず飛ばす** |

**読む順番**: 1行目(何が) → 自分のファイルの最初の行(どこで) → その下(どうやって来たか)。詳しくは本文「エラーメッセージを読む」。
