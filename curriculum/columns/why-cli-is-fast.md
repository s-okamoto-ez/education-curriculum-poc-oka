# なぜ黒い画面のほうが速いのか

> [!NOTE]
> **これはコラムです。読まなくても演習は完了できます。** 気になったときに読んでください。

## 「速い」の正体は、タイピング速度ではない

コマンドラインが速いと言われるとき、多くの人は「キーボードのほうがマウスより速いから」と考えます。**それは、ほんの一部です。**

本当の理由は3つあります。

## 理由1 — 同じ作業を「1回書けば、何回でも」

コマンドライン基礎の冒頭で見た例を思い出してください。

```
grep error *.log
```

`*.log` の `*` は「なんでもいい」という意味です。ファイルが1個でも1000個でも、**このコマンドは1文字も変わりません。**

マウスの操作は、対象1つにつき1回の操作が必要です。**1000ファイルなら1000回。** 対して、コマンドは「1件あたりの処理」を書くだけで、繰り返しはコンピュータがやります。

**これは、プログラミング基礎で書いた `for` ループとまったく同じ発想です。**

```typescript
for (const p of prices) {
  console.log(withTax(p));
}
```

「1件に対する処理」を書いて、繰り返しは任せる。**コマンドラインもプログラミングも、同じ考え方の上に立っています。**

## 理由2 — 部品が「つながる」ように作られている

これがいちばん深い理由です。

Unix(コマンドラインの元になったOS)には、設計思想があります。

> **1つのことをうまくやるプログラムを書け。それらが協調して動くように書け。**

だから `grep` は「探す」しかしません。`wc` は「数える」しかしません。`sort` は「並べる」しかしません。**単機能すぎて、単体では大したことができません。**

ところが、つなぐと化けます。

```
cat app.log | grep ERROR | sort | uniq -c | sort -rn | head -5
```

これは「**エラーログの中で、最も多く出ているメッセージ上位5件**」を出します。6つの単機能な道具をつないだだけで、専用ツールが1つできあがりました。

**GUIのアプリは、こうはいきません。** エクセルの出力をそのままPhotoshopに流し込むことはできません。**それぞれが独自の形式でデータを持っていて、間に人間が挟まる必要がある**からです。

コマンドラインの道具は、**全員が「文字の並び」という共通の形式でやり取りする**と決めています。だからつながります。

## 理由3 — 「やったこと」が残る

マウスで行った操作は、**どこにも残りません。** 3ヶ月後に同じ作業をするとき、手順を思い出すしかありません。

コマンドは文字なので、そのまま記録できます。

- 履歴に残る(`↑` キーで呼び出せる)
- そのままメモに貼れる
- **そのままファイルにして、次回は実行するだけにできる**(シェルスクリプト)
- **そのまま人に渡せる**

「先週やったあの作業、どうやったんでしたっけ」に対して、**コマンドなら答えがコピー&ペーストで済みます。**

## だからAIエージェントもコマンドラインを使う

Claude Code のようなAIエージェントが、あなたのパソコンで作業するとき、使っているのはまさにこのコマンドラインです。

**理由は、上の3つがそのままAIにも当てはまるからです。**

- 出力が文字なので、AIが読める
- 部品がつながるので、AIが組み合わせられる
- 何をしたかが文字で残るので、**あなたが後から検証できる**

**3つ目が特に重要です。** AIがGUIをクリックして作業したら、何をしたのか確かめようがありません。コマンドとして残っていれば、あなたは1行ずつ読んで「これは妥当か」を判断できます。

**AIに任せる時代だからこそ、コマンドラインが読める必要がある** というのは、こういう意味です。

## ただし、GUIが劣っているわけではない

公平のために書いておきます。

| 向いている作業 | どちら |
|---|---|
| 決まった手順を、何度も、大量に | **コマンドライン** |
| 探索的な作業。どこに何があるか分からない | **GUI** |
| 見た目を調整する。色を選ぶ、位置を決める | **GUI** |
| 記録に残したい。人に渡したい | **コマンドライン** |

実務では両方使います。**HTML/CSS基礎で開発者ツールを使ったのは、まさにGUIが向いている場面**でした。「どこに何があるか分からない」状態で探索するには、目で見られるほうが速いからです。

## AIへの質問例

- 「Unix哲学(1つのことをうまくやる)について、具体例つきで教えて」
- 「`sort | uniq -c | sort -rn` という定番の組み合わせが何をしているか、1ステップずつ説明して」
- 「シェルスクリプトを書くべき場面と、書かないほうがいい場面を教えて」
