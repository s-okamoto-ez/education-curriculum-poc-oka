# 型は、実は「ドキュメント」でもある

> [!NOTE]
> **これはコラムです。読まなくても演習は完了できます。** 気になったときに読んでください。

## 型を書く理由は、2つある

プログラミング基礎の本文では、型の理由を1つだけ説明しました。**「間違いを、直すのが一番安い場所で見つけるため」**です。

理由はもう1つあります。そして実務では、**こちらのほうを毎日感じます。**

## 保守の現場で、あなたが最初にやること

こういう関数に出会ったとします。

```javascript
function process(data, options) {
  // 200行
}
```

**この関数に、何を渡せばいいか分かりますか。**

`data` とは何でしょう。配列でしょうか、オブジェクトでしょうか。`options` には何を入れればいいのでしょう。

**調べる方法は、3つあります。**

1. 200行を読む
2. この関数を呼んでいる場所を `grep` で探して、実際に何が渡されているか見る
3. 書いた人に聞く

3番は、たいてい使えません。**その人はもう別の現場にいます。** これが保守の現実です。

## 型があると、質問に答えが書いてある

同じ関数に型がついていると、こうなります。

```typescript
type ExportOptions = {
  format: "csv" | "json";
  includeDeleted: boolean;
  maxRows?: number;
};

function process(data: Post[], options: ExportOptions): string {
  // 200行
}
```

**200行を1行も読まずに、以下が分かります。**

- `data` には、投稿の配列を渡す
- `format` は csv か json のどちらか。**それ以外は無い**
- `includeDeleted` は必須
- `maxRows` は省略してよい(`?` がついている)
- 返ってくるのは文字列

**型は、絶対に嘘をつかないドキュメントです。**

コメントは嘘をつきます。書いた当時は正しくても、コードが変わったときにコメントだけ直し忘れる — これは実務で日常的に起きます。**[最終課題の題材](https://github.com/k-kubo-ez/ai-engineer-education) にも「ドキュメントと実装の食い違い」を仕込むと決めているくらい、ありふれた光景です。**

型は違います。**コードが変われば、型も一緒に変えないとエラーになります。** 放置できない仕組みになっています。

## エディタが、あなたの代わりに読んでくれる

もう1つ、地味ですが効く効果があります。

型がついていると、エディタが `.` を打った瞬間に**その先に何があるかを一覧で出してくれます。** `user.` と打てば、`id` `name` `isPremium` が出てくる。

これは単に便利なだけではありません。**「そのオブジェクトに何が入っているかを調べる」という作業が丸ごと消えます。** 保守の現場で、この作業に費やしていた時間はかなりのものです。

## AIにとっても、型はドキュメントです

そして、ここが2026年の話です。

AIエージェントにコードを書かせるとき、**AIも同じ問題に直面します。** 「この関数に何を渡せばいいのか」が分からなければ、AIも推測するしかありません。**そして推測は、しばしば外れます。**

型があると、AIは推測しなくて済みます。**結果として、AIが書くコードの精度が上がります。**

さらに、AIが間違えたときも型が捕まえます。プログラミング基礎の図で見た通りです。

> **型は「AIの出力が正しいか」を、あなたの代わりに1次チェックしてくれる。**

**人間にとってのドキュメントであり、AIにとってのドキュメントであり、そして間違いを止める柵でもある。** これが、面倒でも型を書く理由です。

## ただし、型は万能ではない

演習03で体験することになりますが、**型は嘘をつかされることがあります。**

```typescript
return users.find((u) => u.id === authorId) as User;
```

`as User` は「TypeScriptさん、これは絶対 User だからチェックしなくていいよ」と**あなたが宣言する**構文です。**宣言が嘘だった場合、型は何も守ってくれません。**

そして `find` は、見つからなければ `undefined` を返します。つまりこの宣言は、**しばしば嘘になります。**

**型が守ってくれるのは、あなたが型に正直でいる限りです。**
