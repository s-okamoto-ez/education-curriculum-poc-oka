# 0. はじめに — 最初の準備

**このページは、1〜6のトピックを始める前に、一度だけ読むページです。** コードやコマンドラインに触ったことがなくても大丈夫です。ここに書いてある通りに、上から順に進めてください。

読み終える頃には、「自分のパソコンの中に、このカリキュラムの中身がまるごとコピーされていて、いつでも編集できる」状態になっています。

## 1. GitHubアカウントを用意する

<mark>GitHub</mark>は、これから3ヶ月ずっと使う、コードを保管・共有するためのWebサービスです。

- すでにGitHubアカウントを持っている方は、そのまま使えます
- 持っていない方は、[github.com](https://github.com/) の右上「Sign up」から無料で作成してください(メールアドレスが要ります)

作成したら、**講師にGitHubのユーザー名を伝えてください。** あなた専用の、あなただけが見られるリポジトリ(このページと同じ内容が入った、あなた専用のコピー)への招待を送ります。

> [!NOTE]
> 招待メールが届いたら、リンクを開いて「Accept invitation」を押してください。**今あなたが読んでいるこのページも、実はその「あなた専用のリポジトリ」の中の1ページです。** 招待を受け入れると、ブラウザ上でこのページの続きが読める状態になります。

## 2. 黒い画面(ターミナル)を用意する

これから3ヶ月、ほぼ毎日使う道具です。詳しい説明は[コマンドライン基礎](01-command-line-basics/README.md)で行うので、ここでは**開けるようにするだけ**で構いません。

| OS | 用意するもの |
|---|---|
| Windows | [Git for Windows](https://gitforwindows.org/) をダウンロードしてインストール(選択肢はすべて既定のままでよい)。インストールが終わると「Git Bash」がスタートメニューに現れる |
| macOS | ターミナルはアプリケーション → ユーティリティに標準搭載。Gitはターミナルで下の確認コマンドを打つと、未インストールなら「インストールしますか」というダイアログが自動で出るので、それに従う |
| Linux | ターミナルは標準搭載。Gitが無ければパッケージマネージャで入れる(Ubuntu/Debian系なら `sudo apt install git`) |

> [!IMPORTANT]
> **Windowsの方は、この先ずっと「Git Bash」を使います。** コマンドプロンプトやPowerShellではありません。

**入れたら確かめる。** 黒い画面を開いて、次を打ってください。

```
git --version
```

`git version 2.xx.x` のようにバージョン番号が出れば準備完了です。

## 3. エディタを用意する

<mark>エディタ</mark>は、コードやMarkdownファイルを書き換えるための専用アプリです。メモ帳でも開けなくはありませんが、この先ずっと不便なので、専用のものを入れます。

**[Visual Studio Code](https://code.visualstudio.com/)(通称VSCode)をおすすめします。** 無料で、この3ヶ月で使うほぼ全ての作業に対応しています。上のリンクからダウンロードしてインストールしてください。

**入れたら確かめる。** VSCodeを起動し、何かのフォルダを開くメニュー(File → Open Folder)が使えることを確認してください。まだ開くフォルダはありません。次の手順で作ります。

## 4. 自分のリポジトリを手元にコピーする

ここまでで、「Web上にあるあなた専用のリポジトリ」と「あなたのパソコンに入ったGitとエディタ」が揃いました。最後に、Web上のリポジトリをパソコンの中にコピーします。この操作を <mark>git clone</mark>(クローン)と呼びます。**「なぜこの操作が必要か」「クローンの仕組み」は[Git基礎](02-git-basics/README.md)で改めて説明します。ここでは操作だけ先に行います。**

1. あなた専用のリポジトリのページ(GitHub上)を開く
2. 緑色の「Code」ボタンを押し、表示されたURL(`https://github.com/...` のような文字列)をコピーする
3. 黒い画面で、コピーしたい場所(デスクトップなど、自分が分かりやすい場所)に移動する
4. 次のコマンドを打つ(`<コピーしたURL>` の部分は、手順2でコピーしたものに置き換える)

```
git clone <コピーしたURL>
```

5. 実行が終わったら、`ls` を打って、リポジトリ名のフォルダができていることを確認する

**できたら、VSCodeでそのフォルダを開いてください**(File → Open Folder)。左側にファイル一覧が表示されれば成功です。
