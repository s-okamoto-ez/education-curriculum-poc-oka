# コマンド早見表(チートシート)

`README.md` と演習(Issue)に出てくるコマンドの一覧です。意味を忘れたら、まずここを見てください。本文で概念から説明しているものは「詳しい説明」に章名を書いています。それ以外は、このチートシートの説明が全てです。

> [!TIP]
> **覚えようとしないでください。** 現場のエンジニアも毎回ここを見ています。大事なのは「そういうコマンドがあった気がする」と思い出せることと、`--help` で自分で調べられることです。

## 今どこにいるかを知る(何も変更しない、安全なコマンド)

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `pwd` | 今いる場所(カレントディレクトリ)を絶対パスで表示する | 本文「はじめの一歩」 |
| `ls` | 今いる場所にあるファイル・ディレクトリの一覧を表示する | 本文「はじめの一歩」 |
| `ls -l` | 一覧を、サイズ・更新日時つきで詳しく表示する | 本文「はじめの一歩」 |
| `ls -a` | 隠しファイル(`.` で始まる名前)も含めて表示する | このチートシートのみ |
| `ls -la` | 上の2つを同時に。実務で最もよく打つ形 | このチートシートのみ |

## 移動する

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `cd <パス>` | 指定した場所に移動する | 本文「はじめの一歩」 |
| `cd ..` | 1つ上のディレクトリに移動する | 本文「今どこにいるか」 |
| `cd ~` | ホームディレクトリ(自分専用の置き場)に移動する | このチートシートのみ |
| `cd -` | 直前にいた場所に戻る | このチートシートのみ |

**パスの書き方**

| 書き方 | 意味 |
|---|---|
| `/` | 一番上(ルート) |
| `.` | 今いる場所 |
| `..` | 1つ上 |
| `../..` | 2つ上 |
| `~` | ホームディレクトリ |

## 中身を見る

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `cat <ファイル>` | 中身を全部まとめて表示する | 本文「中身を見る・探す」 |
| `less <ファイル>` | 中身をスクロールしながら読む。`q` で終了 | 本文「中身を見る・探す」 |
| `head <ファイル>` | 先頭10行だけ表示する | このチートシートのみ |
| `tail <ファイル>` | 末尾10行だけ表示する | このチートシートのみ |
| `tail -f <ファイル>` | 末尾を表示し続け、**追記されたら自動で流す**。ログ監視の定番 | このチートシートのみ |

**使い分け**: 数十行なら `cat`、それ以上なら `less`。何千行もあるファイルに `cat` を打つと画面が流れ切って読めません。

## 探す・数える

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `grep <文字> <ファイル>` | その文字を含む行だけを抜き出す | 本文「中身を見る・探す」 |
| `grep -r <文字> <ディレクトリ>` | ディレクトリの中を**まるごと**探す。「この関数どこで使われてる?」に使う | このチートシートのみ |
| `grep -n <文字> <ファイル>` | 何行目かも一緒に表示する | このチートシートのみ |
| `grep -i <文字> <ファイル>` | 大文字・小文字を区別せずに探す | このチートシートのみ |
| `wc -l <ファイル>` | 行数を数える | 本文「中身を見る・探す」 |

## つなぐ

| 記号 | やること | 詳しい説明 |
|---|---|---|
| `A \| B` | Aの出力を、Bの入力として流し込む(パイプ) | 本文「出力をつなぐ」 |
| `A > ファイル` | Aの出力を、画面ではなくファイルに書き込む(**上書き**) | このチートシートのみ |
| `A >> ファイル` | Aの出力を、ファイルの末尾に**追記**する | このチートシートのみ |

> [!WARNING]
> `>` は既存の内容を消して上書きします。`>>` と1文字違いなので、打ち間違いに注意してください。

## 作る・コピーする・動かす

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `mkdir <名前>` | ディレクトリを作る | 本文「作る・動かす」 |
| `mkdir -p a/b/c` | 途中のディレクトリもまとめて作る | このチートシートのみ |
| `touch <名前>` | 空のファイルを作る(既にあれば更新日時だけ変わる) | 本文「作る・動かす」 |
| `cp <元> <先>` | コピーする | 本文「作る・動かす」 |
| `cp -r <元> <先>` | ディレクトリをまるごとコピーする | このチートシートのみ |
| `mv <元> <先>` | 移動する。**名前を変えるときもこれ**(移動先を同じ場所にする) | 本文「作る・動かす」 |

## 消す(取り扱い注意)

| コマンド | やること |
|---|---|
| `rm <ファイル>` | ファイルを消す。**ゴミ箱に入らず、元に戻せない** |
| `rm -r <ディレクトリ>` | ディレクトリをまるごと消す |

> [!CAUTION]
> **`rm` の前に、必ず `ls` で対象を確認してください。** 特に `rm -rf /` のような打ち間違いは、システム全体を消します。この教材の演習で `rm` を使う場面はありません。

## 困ったときに打つもの

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `<コマンド> --help` | 使い方とオプション一覧を表示する | 本文「困ったときの調べ方」 |
| `man <コマンド>` | 詳しい説明書を表示する。`q` で終了 | 本文「困ったときの調べ方」 |
| `Ctrl + C` | 実行中のコマンドを中断する | このチートシートのみ |
| `Ctrl + L` | 画面をきれいにする(履歴は消えない) | このチートシートのみ |
| `↑` キー | 直前に打ったコマンドを呼び出す。**打ち直す前にまずこれ** | このチートシートのみ |
| `Tab` キー | ファイル名を途中まで打って補完する。**打ち間違い防止に必須** | このチートシートのみ |

**`Tab` は今日いちばん覚えて帰ってほしいキーです。** ファイル名を最後まで手で打っている人は、まず打ち間違えます。途中まで打って `Tab` を押せば、シェルが残りを埋めてくれます。埋まらないときは「その名前のファイルは無い」ということなので、**それ自体が確認になります。**

## 権限を変える

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `chmod +w <ファイル>` | 書き込み権限を足す | 演習04 |
| `chmod -w <ファイル>` | 書き込み権限を外す。**Windows(Git Bash)でも実際に効く** | 演習04 |
| `chmod +x <ファイル>` | 実行権限を足す。**Windows(Git Bash)では見た目のみのことがある** | 演習04 |
| `chmod 644 <ファイル>` | 数字でまとめて指定(`rw-r--r--`) | 演習04 |

## 探す(奥まで)

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `find <場所> -name "<パターン>"` | 名前で探す。サブディレクトリの奥まで届く | 演習05 |
| `find . -type f` | ファイルだけを列挙する | 演習05 |
| `find . -type d` | ディレクトリだけを列挙する | 演習05 |
| `<コマンド> \| xargs <次のコマンド>` | 受け取った一覧を、次のコマンドの**引数として**渡す | 演習05 |

**`*`(ワイルドカード)との違い**: `*` は今いる場所の直下しか見ません。奥まで探したいときは `find` を使います。

## プロセスを止める

| 操作 | やること |
|---|---|
| `Ctrl + C` | 今動いているプロセスを止める |
| `ps` | 今動いているプロセスの一覧を見る |
| `kill <プロセスID>` | 指定したプロセスを強制的に止める |

## 環境変数

| コマンド | やること | 詳しい説明 |
|---|---|---|
| `echo $変数名` | 環境変数の中身を表示する。例: `echo $PATH` | 演習06 |
| `export 変数名=値` | 環境変数を設定する(今の黒い画面が開いている間だけ有効) | 演習06 |
| `which <コマンド>` | そのコマンドが `$PATH` 上のどこにあるかを表示する | 演習06 |

**`$PATH` はコロン(`:`)区切りのディレクトリ一覧です。** 名前だけでコマンドを打つと、シェルはこの一覧を順番に探します。`git` や `node` がどこでも使えるのは、インストーラがこの一覧に自分の場所を登録してくれたからです。

## この教材では扱わないが、この先すぐ使うもの

| 用語 | 意味 |
|---|---|
| シェルスクリプト | コマンドを並べて書いたファイル。同じ手順を繰り返すときに使う。拡張子は `.sh` |
| 標準入力・標準出力 | パイプでつながっている「入口」と「出口」の正式名称。エラーだけは別の出口(標準エラー出力)から出ます |
| `.bashrc` などの設定ファイル | `export` を毎回打たなくても済むように、環境変数を恒久的に登録しておく場所 |
